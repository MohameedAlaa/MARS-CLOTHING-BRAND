# Mars Clothing Brand

A modern, responsive e-commerce website for Mars Clothing Brand, showcasing men's and women's fashion collections with an interactive shopping experience.

## 🌟 Features
- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Product Catalog**: Browse collections for men and women with detailed product pages
- **Shopping Cart**: Add items to cart and manage your selections
- **User Authentication**: Sign in functionality for personalized shopping experience
- **Product Filtering**: Easy navigation through different product categories
- **Contact & About Pages**: Learn more about the brand and get in touch
- **Modern UI**: Clean and intuitive user interface with smooth interactions

## 🚀 Getting Started
### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML, CSS, and JavaScript (for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/MARS-CLOTHING-BRAND.git
```

2. Navigate to the project directory:
```bash
cd MARS-CLOTHING-BRAND
```

3. Open in your browser:
   - Simply open `index.html` in your web browser, or
   - Use a local server (recommended):
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js (if http-server is installed)
     http-server
     ```

4. Visit `http://localhost:8000` in your browser
